# el · 英语学习

面向 Android 平板的英语学习应用：打开任意文本文件，它把文件里**词库中没有的单词**列成一张生词表，选中即查、即译，并配一套可点读的 IPA 音标学习卡。

界面分左右两栏，中间竖条可拖动调节宽度：

- **左栏**：生词列表 —— 一行一个生词，单击选词 / 长按选句，底部 `A-` `A+` 调节字号
- **右栏上方**：查询输入 + 翻译信息（原文 / 释义 / 英美音标）+「加入词库」按钮
- **右栏下方**：网页浏览器（默认打开 etymonline 词源）

## 功能

### 生词列表（阅读区）

打开一个文本文件，显示的不是原文，而是**这份文件的生词表**：

- 支持任意文本文件：`.srt` 按字幕格式解析，其余（`.txt` / `.md` / `.log` / 无扩展名……）一律按纯文本空行分段
- 解析时自动清理非正文内容：ASS 样式覆盖标签 `{\fs16\an2\b0}`、HTML 标签、`\N` 转义换行、BOM 与零宽字符
- 双语字幕自动拆分（同一时间轴上的中 / 日 / 韩文字行判为译文），译文同样参与生词统计
- 生成方式：抽取文件里所有英文单词 → 归一化 → **词形还原后滤掉词库里已有的** → 剩下的按**出现次数降序**排列（次数相同按字母序）
- **时态 / 单复数变体不会再被当成生词**：`books`→`book`、`answered`→`answer`、`running`→`run`、`went`→`go`、`children`→`child`、`isn't`→`is`（见下面「词形还原」）
- 每个生词占三行：行首是「`#序号/总数`」和出现次数（如 `#3/42  ×5`），中间是单词本身，下面紧挨着**它在原文中第一次出现的句子**（灰色小字当上下文，超过 140 字截断）
- 文件里的词全都在词库中时，提示「文件里的单词都已经在词库中了」
- 顶部信息栏显示「生词 N · 全文 M 个不同单词 · K 段」
- 底部 `A-` / `A+` 调节字号（12~44sp），不跟随系统字体缩放
- 单击选词、长按选句；长按后拖动可延长选区（可跨行）

### 词库（已知单词表）

上面「生词」的判定依据就是这张词库：**不在词库里的单词才会显示出来**。

- 默认词表是 APK 里的**一个文件**：`assets/wordlist/known_words.txt`，一行一词，去重后 **8636** 个词
- 启动时整份读进内存（HashSet），**不落库**——判定 O(1)，也不占用 SQLite
- SQLite（`known_words.db`）只存用户点「加入词库」加进来的词（通常几十条），升级 App 不会丢
- 右侧查询面板的「**加入词库**」按钮把当前查询的词写入词库，该词会**立刻从左侧列表消失**，下次分析也不会再出现
- 已收录的词，按钮显示为「已在词库」并置灰，避免重复添加
- 几百段字幕文件（约 800 个不同单词）的分析只需几十毫秒

### 词形还原

如果只按字面判断"不在词库就显示"，`books`、`walked`、`went` 全都会被列成生词。所以判定前先把词还原成原形，三步走：

1. **不规则表**：`assets/morphology/irregular.txt`（1376 条，取自 Princeton WordNet 3.0 的 `verb.exc` / `noun.exc` / `adj.exc` / `adv.exc`）——`went`→`go`、`children`→`child`、`better`→`well`、`is`/`are`/`was`→`be`
2. **缩写还原**：`isn't`→`is`、`you're`→`you`、`can't`→`can`、`we've`→`we`
3. **词尾规则**：`-s / -es / -ies / -ves / -ed / -ied / -ing / -er / -est / -ly`，含双写辅音（`running`→`runn`→`run`）与补 `e`（`making`→`make`）

**规则推导出的原形必须在词库里查得到才算数**，这是准确性的关键：

| 例子 | 推导出的原形 | 在词库里？ | 结果 |
| --- | --- | --- | --- |
| `accusing` | accuse | ✓ | 认为已认识，不出现在生词列表 |
| `running` | run | ✓ | 同上 |
| `lens` | len | ✗ | 否决，仍按生词处理 |
| `bachelorette` | — | ✗ | 真生词，照常显示 |

也就是说，这套机制只会"多认"那些能从词库里推出来的词，**不会把真生词吞掉**。同一份 411 段字幕文件实测：生词 **267 → 102**（消掉 62%）。

### 选中后的两个动作

选中文本会先弹出「查询 / 翻译」菜单：

- **翻译** → 就地弹出浮动翻译窗，不打断阅读
- **查询** → 右上「查询」面板显示释义与英美音标，同时右下浏览器自动打开该词的 etymonline 词源页

### 右侧面板

- 中间竖条可拖动，左右宽度自由分配（左栏默认占 60%，两栏各不小于 220dp）
- 右上：查询输入框 + 翻译信息面板（可直接输入单词查询）+「加入词库」按钮
- 右下：带地址栏、返回、刷新与缩放按钮的网页浏览器；地址栏里既可填完整网址，也可直接填单词（自动转成词源查询）

### IPA 音标学习卡

- 把整串音标（如 `ˌɒpəˈtjuːnəti`）**按最长匹配切成单个音素**，逐个渲染成标签
- 音素词库共 53 条：25 个元音、24 个辅音、`ˈ ˌ ː` 3 个重音 / 长音记号、1 个可选音 `(r)`
- 三色区分：元音蓝 / 辅音绿 / 重音橙；英式、美式音标可点击切换
- 点击音素，下方显示中文发音要领与例词；点例词旁的 ▶ 可单独朗读例词
- 音素发声使用 **36 段真实录音**（`assets/ipa/`）；没有独立录音的双元音等回退为朗读例词
- 工具栏菜单「点击音标发声」为全局开关，关闭后点音素不再发声（持久化，重启仍生效）

## 数据来源

翻译与音标全部使用**免 API Key** 的公开接口，无需任何配置即可运行：

| 用途 | 接口 | 说明 |
| --- | --- | --- |
| 单词释义 | 百度 `fanyi.baidu.com/sug` | 免 Key；**不返回音标**，且对整句返回空数据 |
| 音标 | 有道 `dict.youdao.com/jsonapi` | 仅单个单词查询，返回英、美两套 IPA（约 0.3s） |
| 短语 / 整句 | MyMemory `api.mymemory.translated.net` | 免 Key，匿名调用约 5000 词/天 |

音标结果带内存缓存，同一单词不重复请求；单词查询时释义与音标并行请求，少等一轮网络。

默认词表的来源是自备的四份词表：`test/CET4+6_edited.txt`（一行一词，8028 条）与 `a.txt` / `b.txt` / `c.txt`（词典导出格式 `单词 + TAB + 词性. 释义`，共 16737 条）。

合并规则是**只取单词**：a/b/c 按「英文单词 + TAB」切出词条（多个词条挤在同一行也能切开），CET 表逐行取行首单词，最后去重排序，得到 8636 词的 `known_words.txt`。中文释义不随 APK 分发——词表只有 70KB，而不是原始四份的 830KB。

词形还原用的不规则变形表取自 **Princeton WordNet 3.0** 的 `*.exc` 文件（WordNet License，类 BSD，可自由使用与再分发），并裁剪为「原形在 `known_words.txt` 中」的 1376 条。

## 环境与构建

- JDK 17
- Android SDK：`compileSdk 35` / `minSdk 24` / `targetSdk 35`
- Kotlin + ViewBinding（View 体系，未使用 Compose）
- 依赖仅 AndroidX / Material；翻译与 JSON 解析用 `HttpURLConnection` + `org.json`，词库用 Android 自带 `SQLiteOpenHelper`，未引入任何第三方库

在 `local.properties` 里配好 `sdk.dir` 后：

```bash
# 编译 Debug 包
./gradlew assembleDebug

# 安装到已连接的设备
./gradlew installDebug
```

## 音素音频的来源与授权

`app/src/main/assets/ipa/` 下的 36 个 `.ogg` 是**真实录音**，不是 TTS 合成的——TTS 读不出 `ɒ`、`ʃ`、`θ` 这类 IPA 符号，必须用录音。

录音取自 **Wikimedia Commons** 的 IPA 音素录音，多为 CC BY-SA / CC0 授权，可免费使用。逐个文件与 Commons 原始文件名的对照、以及授权说明见 [`app/src/main/assets/ipa/SOURCES.txt`](app/src/main/assets/ipa/SOURCES.txt)。**若要公开发布，请按各文件页面标注的作者与协议署名。**

## 实现要点

几个不直观但必要的地方，改动前值得一看：

- **生词判定只做字面匹配**：归一化只做小写 + 去所有格（`student's` → `student`），**不做词形还原**。这是刻意按「字面不在词库里就显示」的规则实现的，代价见「已知限制」。
- **默认词表不落库**：默认词表是只读数据，进 SQLite 要走「建库 + 8636 次 INSERT + 再查回来」，实测首次启动 **1165ms**；改成直接读一个词表文件进内存后首次启动 **约 410ms**（其中真正的读 + 解析只占 ~75ms，其余是进程冷启动本身的开销），稳态也从 96ms 降到 ~75ms。所以 SQLite 只留用户词条。
- **词表解析有快速路径**：打包的词表是「一行一词」，逐行解析走快速分支（不做正则匹配）——8636 行的正则匹配比直接 trim 慢一个量级。若换成「单词 + TAB + 释义」的词典导出格式，会自动退回 `WordExtractor.firstWord()` 取行首单词。
- **词库升级不丢用户数据**：`DB_VERSION` 3 的 `onUpgrade()` 只删掉历史版本遗留的默认词条（`source <> 'user'`），用户点「加入词库」加的词全部保留。
- **词库缓存与线程**：`warmUp()` / `filterUnknown()` 会读 assets 与数据库，都在后台线程调用；应用启动时已预热一次，界面里的 `isKnown()` 读的是内存缓存。
- **上下文句子**：抽词时顺手记下每个词**第一次出现所在句子**（`WordExtractor.sentenceAt()`：按 `. ! ? ; 换行` 断句，向两侧最多各扫 240 字符，超长截断加省略号），渲染在生词下方，省得回原文找语境。
- **字母范围限定拉丁字母**：分词字符集是 `A-Za-z` + 拉丁重音字母（`cliché` / `résumé`），刻意**不**扩大到全部 Unicode 字母——否则中文也会被当成「单词」抽出来。
- **词形还原用「规则 + 词库验证」而不是纯词表**：纯词表要枚举所有变形（体积大且永远不全），纯规则又会误判（`lens`→`len`）。这里让不规则表与词尾规则只负责**生成候选原形**，再由 `WordRepository` 逐个到词库里验证，验证得上才算认识——既覆盖规则变形，又不会把真生词吞掉。缩写还原后可能还带词形变化（`doesn't`→`does`→`do`），所以最多再做一跳。
- **解析器不挑扩展名**：`SubtitleParserFactory.getParser()` 只用扩展名挑「SRT 专用解析」，其余一律返回纯文本解析器，所以任意文件都能打开。
- **系统栏**：`targetSdk 35` 起 Android 15 强制边到边显示，两个 Activity 都自行把状态栏 / 导航栏 / 刘海区域的 insets 作为根布局 padding，否则内容被系统栏压住。
- **固定浅色主题**：`EnglishStudyApp` 里 `MODE_NIGHT_NO`。界面配色是固定的米白底 + 深字，若跟随系统进入深色模式，Material 的弹出菜单 / 对话框会变深色底，而文字仍是自定义的白色，出现「白底白字」看不清。
- **音标来源**：百度 `/sug` 的释义文本里**没有音标**，所以音标改从有道 jsonapi 单独取；免费词典 `api.dictionaryapi.dev` 在国内网络连不通，未采用。
- **音素音频**：`build.gradle.kts` 里对 `ogg` 设置了 `noCompress`，MediaPlayer 才能用 `AssetFileDescriptor` 直接播放 assets 里的音频。
- **WebView 字号**：WebView 的文字大小 ≈ 系统 `fontScale × textZoom/100`，平板的系统字体缩放会把网页整体放大；默认用 `1/fontScale` 抵消，使网页与阅读器字号观感一致。
- **双语拆分**：靠「是否含 CJK 字符」判断译文行，同一时间轴两行时一行原文一行译文；若各行同属一种文字（单语字幕）则全部作为原文。

## 已知限制

- **词形还原是尽力而为**：不规则的查表、规则的靠词尾规则 + 词库验证，理论上仍可能漏掉少数变形（漏掉的只会继续显示为生词，不会误吞真生词）。专有名词与俚语（`Barney`、`bachelorette`）本来就该显示。
- 多个变形不做合并计数：`walked` 与 `walking` 若都没被认出会各占一行（计数按文中出现的原样 token）。
- 上下文句子按标点与换行切分，遇到缩写点号（`Mr.`）或整段没标点时，切出来的句子可能偏短或偏长。
- 一个词在文中出现多次也只占一行（行首显示出现次数，列表按次数排序）
- 任意文本都按纯文本处理：只有 SRT 按时间轴解析，ASS / VTT 等不做专门解析（仅清理样式标签）
- 界面按横屏平板设计（两个 Activity 均锁定 `landscape`），手机上会偏挤
- 翻译依赖公开免 Key 接口，有速率与额度限制，高频查询可能被限流
- 音标只对**单个单词**查询，短语和整句不显示音标
- 部分双元音与美音卷舌元音（`ɝ` `ɚ` 等）没有独立录音，点击时朗读例词替代
- 示例文件在首次启动时解压到 `Android/data/com.englishstudy.app/files/Documents/`，卸载应用会一并删除
